# Drive Mover

Paste links, one click, everything lands in your Google Drive.
One combined folder, one numbered subfolder per link.

Set these Space secrets before first use:
- GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET (Google Cloud OAuth web client)
- GOOGLE_REDIRECT_URI (this Space URL + /auth/callback)

Then open the app and tap "Connect Google Drive".
